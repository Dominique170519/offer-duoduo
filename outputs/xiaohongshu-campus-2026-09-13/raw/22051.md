参与企业级 API 网关与 AI 网关平台的核心建设，涵盖高性能网关、流量治理、API 资产管理及 Agent Infra 等方向。一方面通过 API 网关保障业务流量稳定、安全、高效运行。 工作职责： 1、参与 API 网关与 AI 网关平台的设计、开发、测试和持续优化，建设稳定、高性能、可扩展的网关基础设施； 2、参与 API 网关流量治理能力建设，包括动态路由、负载均衡与服务发现；限流、熔断、降级、重试及超时控制；灰度发布、流量调度与访问控制；链路追踪、指标监控、日志分析与故障定位等；
3、支持公司重大项目和核心业务接入，参与容量评估、性能压测、稳定性保障、应急响应及疑难问题排查； 4、参与面向 Agent Infra 的 AI 网关能力建设，包括 Agent Registry（注册、发现、元数据及生命周期管理）、Agent Identity（身份标识、认证、授权及可信调用）、Agent Gateway（调用路由、协议适配、策略治理、安全控制及可观测性）。
1、本科及以上学历，计算机科学、软件工程、网络工程、人工智能等相关专业； 2、具备扎实的计算机基础，熟悉数据结构与算法、操作系统、计算机网络、数据库等基础知识； 3、熟悉 Go、Python 中至少一种编程语言，具备良好的编码习惯，并愿意在实际工作中学习和使用两种语言； 4、理解 HTTP/HTTPS、TCP/IP、DNS 等基础网络协议，对服务间通信和网络代理原理有一定认识；
5、对大语言模型、AI Agent 或 Agent Infra 有兴趣，愿意持续学习 MCP、A2A、工具调用等新技术。 【加分项】：有网关、反向代理、微服务、分布式系统或高并发服务相关的课程项目、实习或个人项目经历；了解 Service Mesh、Envoy、Nginx、APISIX、Kong、Higress 等相关技术或项目。
