部门肩负着以 AI 重构公司级下一代质量与研发效能体系的使命，致力于打造一套面向未来的软件研发基础设施。 参与公司级 AI Agent、AI Coding Agent 与 AI 个人助理的研发，让 AI 能够理解需求与业务上下文，完成任务规划、代码实现、测试验证、发布部署和问题诊断，并在安全、可控、可评估的前提下，从“研发辅助工具”逐步升级为能够承担真实交付任务的“智能工程伙伴”。
工作内容包括但不限于 Agent Harness 架构、代码与业务上下文理解、工具与技能生态、Memory 与个性化系统、Agent 评测与数据飞轮等，并持续探索大模型在真实软件工程场景中的可靠落地。
1、本科及以上学历，计算机等相关专业； 2、对打造真正能交付任务的 AI Agent 有热情，对 AI 产品和软件工程体验有审美，能把体验目标翻译成系统目标； 3、具备扎实的工程功底，精通 Go / Java / Python / C++ 至少一门，深入理解大模型应用运行机制（function calling、流式交互、推理服务、MCP 等协议生态），熟悉主流 Agent Harness框架与 AI Coding 工具链，理解模型能力与系统能力的边界，懂得用 Harness 设计持续放大 Agent 表现；
4、兼具研究深度与工程落地能力，能将前沿研究转化为真实产品价值； 有 Code Agent、代码智能、Agent 评测体系、CI/CD 与测试验证平台、高并发在线服务等相关经验者优先； 5、思路清晰、自驱力强，具备优秀的问题拆解和系统设计能力，AI Native 工作方式、自己就是 AI Coding 重度用户，能独立定义并打穿复杂问题； 6、在 ACL / EMNLP / NAACL / COLING / CVPR / ICCV / ICLR / NeurIPS 等顶会顶刊一作发表过论文，或有头部大厂 / 顶级实验室实习、代表性开源项目经历者优先。
