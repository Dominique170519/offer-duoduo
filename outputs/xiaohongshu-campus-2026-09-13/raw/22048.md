参与小红书云原生 Infra 核心建设，涵盖混部调度、效能提升、GPU 调度、Agent Infra、混合云等方向，在高规模生产环境中深入打磨 Kubernetes 及容器调度平台的核心能力。 工作职责： 1、参与 Kubernetes 架构设计与开发，在深入理解 Kubernetes 原生架构基础上，参与 Kubernetes 核心组件的设计与开发； 2、参与 Kubernetes 集群全面性能分析，优化关键节点、组件和流程，提升整体系统的稳定性和响应速度；
3、参与 Kubernetes 集群的稳定部署、监控与维护工作，确保集群在高负载环境下的可靠运行，并持续完善平台化能力； 4、参与公司容器调度平台的架构设计和核心功能开发，包括容器资源管理、调度优化、应用弹性和资源弹性等方向； 5、参与公司混部调度方案落地，优化集群资源的整体利用率；研究并改进 Kubernetes 调度算法，提升集群资源分配效率和稳定性；
6、参与公司智能体 Agent Infra 产品的设计与开发，探索 AI 与云原生基础设施深度融合的工程实践。
1、本科及以上学历，计算机、软件工程等相关专业，具备扎实的计算机基础（数据结构与算法、操作系统、计算机网络等）； 2、熟悉至少一种编程语言（Go / Python / Java / C++ 等），具备良好的编码习惯，能够在 Linux 环境下独立开发和调试； 3、对分布式系统、云原生技术（Kubernetes、Docker、容器调度等）有浓厚兴趣，了解其基本原理者优先；
4、具备主动学习能力、良好的逻辑思维和团队协作精神，能够积极推动问题的分析与解决； 5、有 Kubernetes 相关课程项目、开源贡献或实习经历者加分；对调度算法、资源管理、性能优化有研究者优先； 6、对 AI Infra、GPU 调度或 Agent 基础设施有了解或兴趣者加分。
