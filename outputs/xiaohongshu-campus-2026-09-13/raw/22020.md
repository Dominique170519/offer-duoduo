团队介绍 点点是小红书面向用户打造的 AI 应用，依托丰富的真人笔记理解用户需求，为用户提供真实、可落地的解决方案；团队主要负责 Agent、大模型、生成式 UI 和评测体系研发。 岗位职责： 1、负责点点 Agent 核心架构与关键模块的设计研发，包括任务理解与拆解、规划与推理、多轮上下文管理、长期记忆、Tool 选择与执行、状态管理及异常恢复，持续提升 Agent 在复杂真实场景中的自主决策和任务完成能力；
2、参与大模型在 Agent 场景中的能力建设与适配，围绕推理规划、指令遵循、Tool Use、长上下文等方向，开展推理轨迹构建、后训练数据建设及新模型能力验证；连接小红书真人内容、结构化信息和行业供给，持续优化工具检索、多工具协同、结果理解及失败恢复效果； 3、探索生成式 UI 的产品与技术形态，根据用户需求、内容证据和 Agent 执行状态，动态生成和组织答案、卡片、对比组件及交互流程，建设可控、可解释且符合用户决策逻辑的交互体验；
4、建设评测驱动的研发体系，包括端到端任务评测、模型与工程专项评测、Tool 评测及真实 Tool 实验环境；通过任务结果和执行轨迹定位模型、工程与 Tool 的能力边界，驱动技术迭代和版本决策； 5、深入理解真实用户需求，与产品、算法、客户端、服务端及设计团队协作，推动技术方案从探索验证到线上落地，并对最终用户体验、效果、稳定性、时延和成本负责。
1、本科及以上学历，计算机等相关专业； 2、具备扎实的计算机基础和优秀的 Coding 能力，深入理解数据结构、算法、操作系统、计算机网络及软件工程，熟练掌握 Python、C++、Java、Go、JavaScript 等至少一门主流编程语言； 3、深入理解大语言模型和 Agent 的核心原理，熟悉 Transformer、Prompt、上下文管理、推理规划、Tool Calling、RAG、模型训练或评测等相关技术； 4、具备大模型或 Agent 项目的全链路实践经验，参与过从问题定义、方案设计、数据构建、模型或框架开发、Tool 接入、评测验证到上线迭代的完整过程，并能清晰说明个人贡献与技术取舍；
5、在 Agent 架构、大模型训练与后训练、推理与规划、上下文与记忆、Tool Use、搜索与检索、生成式 UI、多模态理解或模型评测等至少一个方向具有深入实践和独立判断； 6、对 Agent 和大模型前沿技术保持敏感，具备快速学习、独立研究和持续探索能力，能够判断新技术的实际价值及适用边界； 7、具备良好的沟通与协作能力，能够清晰表达技术判断、实验结论和方案取舍，并推动跨职能团队共同完成交付。
【加分项】 1、以第一作者身份在相关领域 CCF A/B 类顶会或顶刊发表过有影响力的论文；或在 ACM 类编程竞赛中获奖，并取得全国或全球有竞争力的名次； 2、有国内外头部科技公司核心技术团队实习经历，在具体技术方向上独立完成过复杂需求或核心项目；或参与过具有行业影响力的研究课题，并承担核心工作。
