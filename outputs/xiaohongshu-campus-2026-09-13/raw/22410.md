团队与业务 所在团队负责小红书种草度量体系与灵犀 AI 数据洞察产品的研发。灵犀是商业化核心的数据洞察平台：基于小红书一方数据为广告主提供人群画像洞察、人群对比分析与种草策略建议，让广告主"看清人群、选对人群"。团队同时建设种草效果化度量、一方数据基建等数据智能方向，是商业化"从投放到度量"链路的关键一环。
---
岗位职责 1、参与灵犀 AI 数据洞察产品的全栈研发，覆盖人群画像总结 / 对比 / 解读、AI 专家工作台等核心能力 2、参与大模型驱动的数据分析链路建设：Prompt 工程与调优、多模型评测、Badcase 回收与迭代 3、参与画像指标基建与数据链路建设，让海量一方数据变成广告主可消费的洞察 4、与产品、算法、数据紧密协作，从广告主真实决策场景出发定义洞察产品能力
1、2027 届本科及以上学历，计算机、软件工程、数据科学等相关专业优先 2、扎实的编程能力，精通 Java / Go / Python 至少一门；对数据处理与 SQL 有基本功底 3、熟练使用主流 AI Coding 工具，能结合大模型 / Agent 完成完整业务模块的设计与实现 4、具备前后端全链路问题的分析与解决能力
加分项 1、有 LLM 应用、Prompt 工程、RAG、数据可视化相关的完整项目经验 2、对数据分析、用户研究、营销科学有兴趣
