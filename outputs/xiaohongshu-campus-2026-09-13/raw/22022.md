把“还没被证明的体验设想”做成可运行、可测量、可上线的端到端原型与实验，在真实业务场景里快速验证、快速迭代，把有效结论变成可推广的成熟方案。 工作职责： 1、构建可运行的 Agent 核心链路：围绕社区新交互场景，设计并实现 Agent 的核心能力，你需要把一个“看起来可行的想法”，真正落成可以跑、可以测、可以复盘的系统；
2、端到端负责从想法到验证的完整闭环：你需要从 0 到 1 推动一条探索链路，我们希望你不是只完成开发任务，而是能对“这个方向是否成立”给出工程化判断； 3、与多角色协作，把模型能力做成产品能力：把需求变成可执行的 agent spec，把模型能力变成稳定的系统能力； 4、参与前沿方向的Research和模型后训练，在交互领域持续跟踪和突破能力上限。
1、本科及以上学历，计算机、人机交互、人工智能等相关专业，有 CCF-A 类一作论文者优先； 2、有“从 0 到可验证”的完整交付经验：能把探索做成可运行系统，并用评测/数据输出结论； 3、良好的跨团队协作与表达能力：能清晰描述权衡、边界与风险。 【加分项】 1、做过 Agent/Workflow 系统：多工具编排、函数调用/插件体系、任务队列与调度、长期任务与状态恢复；
2、智能体验方向经验：多模态理解驱动 UI、对话式交互、创作辅助、推荐解释/可控性、内容结构化与可编辑体验； 3、熟悉 多模态 Agent（图像/语音/视频）或在内容/搜索/推荐场景做过 agent 化探索； 4、在 HCI/交互/AI 体验相关方向有公开影响力：论文、专利、开源项目或行业分享。
