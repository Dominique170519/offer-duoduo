关于我们： 质效研发部肩负着以 AI 重构公司级下一代质量与研发效能体系的使命。 我们希望打造一套面向未来的软件研发基础设施，让 AI 能够理解需求与业务上下文，完成任务规划、代码实现、测试验证、发布部署和问题诊断，并在安全、可控、可评估的前提下，从“研发辅助工具”逐步升级为能够承担真实交付任务的“智能工程伙伴”。
我们将深入小红书复杂业务场景，持续探索 AI Coding、AI Testing、AI Agent、Agent Harness 与大模型应用，让每一位研发工程师获得更强的创造力和交付能力，让人与 Agent 共同组成新一代高效研发团队。
工作职责： 1、设计和实现面向下一代软件研发&质量的 AI Agent 产品与基础设施，覆盖研发、测试设计、用例生成、执行验证、缺陷诊断与质量度量全流程，推动 Agent 在受控环境中独立完成真实工程与质量保障任务； 2、攻坚 LLM 工程化核心难题，解决大模型在实际研发场景的落地瓶颈：上下文理解、长程推理、多步骤任务规划；
主导智能代码生成、智能测试、智能运维等核心模块架构设计； 3、驱动技术范式革新，深入理解小红书多元业务场景（社区/电商/多媒体/搜推广），用 AI 重新定义研发流程； 探索 Multi-Agent 协作、AI 自我进化等前沿方向； 4、参与公司级 AI Agent、Agent Harness、Skill、工具和知识生态建设，推动不同研发 Agent 之间的能力发现、任务协作与资产复用；
沉淀最佳实践、技术标准和开发框架，帮助业务团队快速构建专属 AI 能力。
1、2027届本科及以上学历应届毕业生，计算机、软件工程、人工智能等相关专业优先； 2、具备扎实的计算机基础，熟悉算法与数据结构、操作系统、计算机网络、数据库及软件工程； 熟练掌握至少一种主流编程语言，并具备良好的代码质量意识； 3、具备 AI Native 思维，深度使用过 AI Coding 或 Agent 产品； 4、理解大模型、上下文工程、工具调用、Agent Harness 和 Agent 基本工作机制，有相关项目实践者优先；
5、具备较强的产品工程能力，能够从真实用户问题出发，独立完成需求分析、技术方案、产品实现和效果验证； 6、对 AI 重构软件研发具有强烈兴趣和长期信念，具备快速学习、独立思考和动手能力，能够在高不确定性环境中持续探索并交付结果。
加入我们，你将获得: 1、在小红书复杂而丰富的真实业务中，参与公司级AI研发基础设施建设； 2、深度参与AI Coding、AI Testing 等前沿方向，解决Agent规模化落地中的真实工程难题； 3、从产品定义、技术设计到生产落地完整负责项目，快速成长为兼具AI能力、系统能力和产品意识的Product Engineer； 4、完善的Mentor带教和成长机制，与一群对技术和产品充满热情的伙伴，共同探索人机协作的软件研发新范式。
