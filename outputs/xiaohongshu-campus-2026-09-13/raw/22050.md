参与小红书南北向接入架构建设，涵盖七层负载均衡（RGW）和 GSLB 全球负载均衡的运维开发工作，支撑峰值数千万 QPS 的业务场景，负责流量平台、内外网调度、高可用系统的设计与迭代。 工作职责： 1、自建基础设施：参与接入层核心组件的自研与自建，包括自研负载均衡、自建证书体系等，降低对外部依赖，提升自主可控能力；
---
2、国际化流量架构：参与 GSLB 海外解析与全球流量调度体系建设，支撑业务的国际化拓展，解决跨地域、跨运营商的访问质量与合规问题； 3、稳定性保障：维护接入层核心链路的稳定性，建立完善的监控告警体系，快速响应和处理线上问题； 4、核心产品运维与优化：负责团队内部核心产品的日常运维、性能调优与故障排查，以及接入平台的持续优化；
5、平台化与工程化：通过持续优化平台化能力提升运维效率，以工程化思维推动系统稳定性和运维提效。
1、本科及以上学历，计算机科学等相关专业，熟练掌握 Linux 环境下的 C / C++ / Go / Python / Shell 等至少一种编程语言； 2、网络基础扎实，深入理解 TCP/IP、HTTP/HTTPS、DNS、NAT、负载均衡等网络协议与服务； 3、熟悉公有云环境，了解 Nginx、Envoy 等七层网关技术，有运维平台开发经验者优先； 4、对系统稳定性、高可用架构和大规模流量治理有浓厚兴趣，具备快速学习能力和团队协作精神。
