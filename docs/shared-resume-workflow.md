# 网申资料与云端简历协作

## 数据边界

- 云端母版保存允许同步的公共事实、简历文案及文档配置。公共字段包含兴趣爱好和最早到岗时间。
- 插件的网申专用补充资料独立保存在本机 `APPLICATION_PROFILE_KEY`，按经历 ID 关联；上传始终经过云端字段白名单。
- 网申中心保存公共事实时更新关联母版，网申文案单独保存。岗位简历的定制文案不反向覆盖母版。
- 删除简历条目后，其本机补充资料进入可恢复档案；清空本机资料时才一并清除档案和填写历史。

## 并发与版本

母版使用递增 `revision`，更新请求携带 `expectedRevision`。版本不符返回 409，不按客户端时间决定覆盖。网页保留编辑内容并支持另存副本；插件保留本地与云端版本供选择。

岗位定制在创建时固定母版版本和 JD 快照。AI 建议按项确认，应用前检查原文，避免把过期建议应用到已修改内容。用户确认后才作为可同步岗位版本发布；普通编辑使版本回到草稿状态。

插件拉取已确认版本，保留旧版历史，并记录实际填写所用的公共资料快照及来源版本。记录不代表招聘网站已经提交成功；页面地址去除查询参数和片段。

## 升级与验证

- API、网页、插件需要配套升级；旧的网页写入请求缺少 `expectedRevision` 会被拒绝。
- PostgreSQL 版本号保存在现有 JSON 数据中，旧记录按版本 1 读取，不需要新增 SQL 列。内存存储与 PostgreSQL 存储均执行版本比较；本次集成测试使用内存存储，未连接真实 PostgreSQL。
- 插件首次读取会迁移旧资料中的本机补充字段。扩大同步字段和文档资源范围后，需要重新接受同步说明。
- 自动化覆盖公共事实合并、私有字段隔离、删除恢复、版本冲突、批量更新原子性、母版与 JD 快照、AI 建议选择、岗位版本同步和填写记录。
- 本地网页验证覆盖双窗口冲突及另存副本、母版保存、AI 建议选择和确认发布。AI 使用确定性的测试实现；尚未验证生产模型、真实招聘网站提交或生产 PostgreSQL 并发。
